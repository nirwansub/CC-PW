## Pembanding rancangan

CC = Corporate Communications: Strategist, Creative, Publicist, Executor. PW = People & Workplace: Curator, Developer, Workplace, Executor. Rancangan universal 32 soal menggantikan versi lama lima soal per posisi.

Pre-assessment: 24 SJT/MCQ + 4 esai pendek + 4 kasus lintas posisi. Implementasi kasus lintas posisi terdiri dari 2 MCQ dan 2 esai: total 26 MCQ dan 6 esai. Preferensi posisi hanya minat; delapan role tetap dipetakan. Routing maksimal dua role, dengan flag role ketiga berdekatan tanpa otomatis ditambahkan.

Profil opsional langsung sesudah submit; English boleh kosong dan seluruh profil tidak memengaruhi skor, ranking, kecocokan atau routing. Handbook prinsip bersama dan modul role, kemudian post-test kasus baru dan practical. Dashboard Assessment dan Personal Profile terpisah, review manual untuk pengecualian.

Riwayat menunjukkan permintaan user tentang larangan copas, wajib fullscreen dan penghentian saat pindah tab. Riwayat durasi memiliki versi berbeda; angka timer produksi perlu diperlakukan sebagai pengaturan pilot.

## Masalah yang ditemukan dan diperbaiki

1. AI dapat mengembalikan kurang dari enam hasil esai walaupun JSON valid. Trial versi awal menghasilkan respons tidak lengkap lalu timeout pada retry. Schema baru mewajibkan properti untuk setiap ID soal dan setiap capability yang tepat. Struktur hasil dinormalisasi sebelum validasi evidence; jawaban yang tidak lengkap tetap ditolak.
2. Urutan soal dan opsi selalu sama. Total sinyal opsi indeks pertama pada bank MCQ lebih tinggi (315 dibanding 270, 270 dan 279 untuk indeks lainnya). Tampilan kini diacak per sesi dan disimpan; resume memakai urutan sama dan ID pilihan tetap canonical sehingga skor tidak berubah. Perbedaan kualitas/kalibrasi isi opsi tetap perlu ditinjau.
3. Post-test/practical sebelumnya memerlukan tombol tambahan untuk memulai penilaian. Client kini memulai grading setelah submit diterima. Tombol retry masih tersedia saat penilaian gagal. Perubahan ini diperiksa lewat kode dan tes; klik submit penuh di browser cloud belum dapat diuji karena fullscreen ditolak.
4. Client memanggil /api/index yang diarahkan 308 oleh clean URL Vercel. Fetch dan beacon kini langsung memakai /api, sesuai route produksi yang diuji.

## Bukti trial

Semua data uji sintetis diberi nama [QA AUDIT 01 OCT]; tidak mewakili kandidat nyata. Trial memakai jawaban untuk memeriksa jalur kerja dan penyimpanan. Validitas prediksi kemampuan memerlukan pilot manusia.

- Sebelas tes otomatis lulus, termasuk alur lengkap, deadline, stale autosave, single-attempt, non-scoring profile, exact evidence, schema seluruh esai, dan pengacakan dengan ID stabil.
- Build lokal dan pemeriksaan sintaks lulus.
- Trial API produksi setelah perbaikan menjalankan 30 request; response gagal yang diharapkan adalah 403/409 untuk gerbang tahap. Tidak ada response gagal di luar skenario yang diharapkan.
- Lima grading memakai OpenAI asli berhasil pada percobaan pertama: pre 17,2 detik; post Workplace 10,1; practical Workplace 12,1; post Curator 9,1; practical Curator 10,8.
- Pre menghasilkan dua role: Workplace dan Curator; semua delapan role memiliki skor. Role ketiga hanya flag.
- Mengubah profil English/MBTI/zodiak/hobi tidak mengubah hasil pre. Mengisi checklist validasi dan catatan tidak mengubah hasil pre.
- Kedua role membaca materi, menyelesaikan post dan practical, lalu hasil dapat dibaca kembali dari admin.

Empat tahap lanjutan diberi flag review oleh AI. Jawaban sintetis generik memang memerlukan validasi; tahap-tahap tersebut tetap memiliki skor dan status grading complete. Skor ini hanya bukti fungsi perhitungan.

Uji pengaman tambahan produksi: sesi soal diacak, urutan resume stabil, violation mengubah status menjadi terminated, akses materi kemudian ditolak 403 dan start kedua ditolak 409. Violation disimulasikan melalui API; ini tidak membuktikan deteksi tab langsung di browser.

Endpoint admin-config/admin-bank tanpa cookie ditolak 401. URL /lib/assessment.js, /lib/grading.js dan /test/api.test.js ditolak 404. Repository nirwansub/CC-PW terkonfirmasi visibility public.

Browser nyata menampilkan landing page, form awal, status penghentian QA, dan dashboard akhir dengan Workplace/Curator serta post/practical submitted. Fullscreen request menampilkan “not granted”, sehingga trial klik seluruh soal dan deteksi focus/tab di browser cloud belum selesai. Pengujian browser desktop yang mendukung fullscreen tetap diperlukan.

Pemindaian log error deployment kode perbaikan selama audit tidak menemukan log. Response error yang ditangani tidak selalu dicatat sebagai console error, sehingga hasil log ini perlu dibaca bersama bukti request trial.

## Prioritas sebelum skrining operasional

1. Buat repository private agar rubrik/bobot tidak terbuka. Audit tidak mengubah visibility repository.
2. Review dan kalibrasi bank pertanyaan, sinyal opsi, sepuluh capability agregat, bobot role, threshold role ketiga dan bobot gabungan. AI grading yang berfungsi belum membuktikan validitas asesmen.
3. Lengkapi validasi practical Creative dengan karya visual dan role lapangan dengan observasi yang relevan. Format sekarang menilai jawaban tertulis.
4. Putuskan timer, dukungan perangkat, dan lakukan trial manusia pada browser desktop, termasuk copas, perpindahan tab, keluar fullscreen, timeout dan putus koneksi.
5. Rapikan akhir alur kandidat: saat semua tahap selesai, dashboard masih menyebut progres dan status teknis “submitted”; belum ada layar konfirmasi assessment selesai.
